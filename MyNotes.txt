How a session cookie becomes `currentUser`:
In lib/actions.js the currentUser function returns userFromToken(jar.get("chalk_session")?.value);
This grabs a cookies called chalk-session from the user.
Also the loginAction function is what retrives the cookie for a known user
or creates a new cookie and session table in the DB for a new user.
usersFromToken is where the cookie/token becomes the current user by creating a join
between users and session tables based on the userID which is determined by the cookie value.

How a post body gets from the compose form onto the wall:
The composePage function in app/compose/page.js displays a page to make a post and
takes the user input and gives it to createPostAction. That funtion takes the data and adds it to 
the database, which means it can be displayed.

How i fixed it:

I added this function:
    function cleanTheNasty(str) {
        return str
            .replace(/&/g, "&amp;")
            .replace(/</g, "&lt;")
            .replace(/>/g, "&gt;")
            .replace(/"/g, "&quot;")
            .replace(/'/g, "&#039;");
    }
that sanatizes escape characters.
Then inside the createPostAction function, I call     const safe = cleanTheNasty(body);
right before the line to add 'body' to the DB but instead it adds 'safe' to the DB so not the post displays text only.
